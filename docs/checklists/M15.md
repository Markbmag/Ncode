# M15 · Dashboards people read: manual checklist

Install: in `backend`, `pip install -r requirements.txt` (adds **Pillow**, which draws the chart
pictures in emails; without it emails keep their simple bars). No new frontend packages. On start
the app database gets migration 0011 (saved versions of questions and dashboards). New optional
settings: `NCODE_HISTORY_KEEP` (50), `NCODE_EMAIL_LANGUAGE` (en), `NCODE_CHART_FONT`. **Back up
`backend/data/ncode.sqlite` first.** Then `pytest`, `npm test`, `npm run lint`, `npm run build`,
`npm run e2e`.

Existing installs keep their Factory demo examples as they are; a new install's demo has the weekly
*Work orders* card and a *Scrap rate by week* card with a 2 % target.

## 1. The "done when": a foreman's morning

- [ ] On a phone (or a phone-sized window), open *Production overview* in Russian. Each number card
      says what period it shows (*Прошлая неделя*), the change in words (▼ 0,4 п. п. к предыдущей
      неделе), the target and "this week so far". Green means good, red bad; scrap going down is green.
- [ ] *Фильтры* opens the filters as a sheet; cards are one column, numbers two side by side, no
      sideways scrolling. The title is not cut off.
- [ ] *Следить* → *Every Monday* (without an email address it asks for one). Admin → Subscriptions
      → the digest → *Send now*: the email lists the biggest changes in Russian sentences with
      Russian numbers (1 263 → 1 077) and small chart pictures that show in Outlook / Gmail / the
      phone's mail app.

## 2. Readable KPIs

- [ ] A number question with dates → *Customize* → *Number*: *Compare with the period before*,
      *When the number goes up* (good / bad / no colour), *Target*, *Small trend line*.
- [ ] Without dates the last row is compared with the row before.
- [ ] Every dashboard shows *Data from 10:30 · 5 min ago*; *Refresh all* reads everything again.

## 3. History, restore, undo

- [ ] Save a question three times (change the filter in between) → *History* lists three versions
      with who and when; open the first: its filters / SQL are shown; *Restore* brings it back and
      the version you had is still in the list.
- [ ] The same for a dashboard. A viewer sees the history but cannot restore.
- [ ] Editing a dashboard: move, resize, add and remove cards → Ctrl/Cmd+Z and Ctrl/Cmd+Shift+Z (and
      the buttons) undo and redo them; *Cancel changes* goes back to the saved dashboard.

## 4. Follow and digests

- [ ] *Follow* → *Every morning*: yesterday against the day before. A day with small changes says
      *No big changes*.
- [ ] Counts and sums name the line or reason that changed most ("mostly Press line (−48)"); rates
      name the line that moved most instead of adding rates up.
- [ ] The digest appears on *Subscriptions* with a *Digest* badge; *Unfollow* stops it.
- [ ] A normal subscription now also shows chart pictures.

## 5. Templates

- [ ] *Dashboards* → *From a template* → *Downtime Pareto* on the demo: the guesses are right, the
      preview shows a card, *Create* makes the questions and the dashboard in your own collection.
- [ ] *OEE* on the demo comes out around 50 % (480 planned minutes per day and line). On a database
      without a plan table it says which part is missing rather than failing.
- [ ] A wrong column choice gets a sentence, not an error.

## 6. No regressions

- [ ] English numbers look as before (1,263; 0.8 %). The M12 checklist's 6-click path still works.

## What I verified here

- Backend 857 tests incl. live PostgreSQL 16, MariaDB 10.11, SQL Server 2022. Frontend 295 tests,
  lint, build. Browser 51 tests incl. the demo dashboard on an iPhone, history and restore, Follow,
  and a dashboard from a template.
- A real weekly digest of the demo dashboard, sent through the mail code in English and Russian and
  looked at on a phone-width screen: four sentences, three chart pictures, Russian numbers.
- Fixed while verifying: numbers in the Russian interface used the browser's format (0.8%) instead
  of Russian (0,8 %); long dashboard names were cut on phones; "And 1 smaller changes"; the Russian
  "more changes" line; suggestion titles reading "Total Total".
- Known limits: *Follow* for a metric works on the server but has no button yet (glossary / data
  model); the demo's line and reason names are English in the Russian demo (they are data); on a
  phone the last date on a chart's axis can be cut at the edge. One Kanban browser test failed once
  in a full run and passed in 16 repeats and the next two full runs.
