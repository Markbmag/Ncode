# M11 · First steps & plain language: manual checklist

Install: no new packages. On start, the app database gets migration 0009 (table names, translations,
recently viewed, personal settings, glossary, verified). The **Factory demo** database is created in
`backend/data/demo/factory.sqlite` together with its examples (set `NCODE_DEMO_LANGUAGE=ru` before the
first start for Russian example names; `NCODE_DEMO=false` to skip the demo). **Back up
`backend/data/ncode.sqlite` first.** Then run `pytest`, `npm test`, `npm run lint`, `npm run build` and
`npm run e2e`.

## 1. A newcomer's first steps (the "done when")

Create a new user (Admin → People) and sign in as them, once in English and once in Russian.

- [ ] Home shows *Your first steps in Ncode* (0 of 5), *Start here · Factory demo* with the
      *Production overview* dashboard and five questions, and an empty *Recently viewed*.
- [ ] Open *Production overview*: a number, a weekly line chart, downtime by reason (horizontal bars),
      scrap per line and the latest vehicles. A sentence under each card title says what it shows.
- [ ] Change *Period* or type a line (e.g. `Final assembly`): every card follows.
- [ ] Copy a VIN from *Latest vehicles*, then go to Search, paste it and press Enter. Open the record:
      readable field names (Модель, Цвет … in Russian).
- [ ] New question → Data: *Downtime events* (*Простои*) → *What to count or sum*: count → *Group by*:
      Line → a result appears with a sentence under it. Save it.
- [ ] Back on Home: all five steps are ticked and the list has gone. *Recently viewed* shows the
      dashboard and the question.

## 2. Plain words in the builder

- [ ] Only Data · Filter · Summarise show at first; *More steps* opens the rest with a hint each.
- [ ] Join choices read *Keep all rows* / *Only matching rows* / *All rows of both*; sort reads
      *Biggest first* / *Newest first* / *A → Z*.
- [ ] Result headers read *Sum of Total*, *Created at: month*, *Count*; empty values show as *—*.
- [ ] A saved result shows *Saved result from … ago* with a link to read the data again. *Explore the
      columns* and *Readable dates* are in the ⋯ menu.

## 3. Names, glossary, verified

- [ ] Admin → **Data model** (its own tab): give a table and a column a display name, a description and
      a Russian translation. Pickers, Browse, Search, results and the record panel use them in both
      languages; hovering shows the description.
- [ ] **Glossary**: as an admin add *OEE* with English and Russian text, a synonym and a link to a
      metric. Everyone can search it, also in Russian (ё = е). *See glossary* appears next to the linked
      metric in the data model.
- [ ] As an admin, ⋯ → *Mark as verified* on a question and a dashboard: the badge shows in lists,
      searches put it first, and changing the question's query (not its name) removes the badge after
      a warning.

## 4. Sharing and the menu

- [ ] As a normal user, save a question in your own collection → **Share** explains *Move to a shared
      collection* and *Give a person or group access*. Moving a dashboard offers to bring its questions.
- [ ] The menu shows *Look up*, *Answer questions* and *Saved and shared*, at desktop and phone width.
- [ ] Empty pages (Search, Browse, Combine, Uploads, Subscriptions, Library, Dashboards) offer one
      action and one example.

## 5. Admin

- [ ] Home → *Start here* → *Change* (admin) → choose another shared collection → it shows for
      everyone. *Show none* removes it.
- [ ] Admin → Databases → hide the demo → it disappears for everyone; show it again.

## 6. No regressions

- [ ] Search, Browse and CSV export work as before; the M10 checklist's security items still pass.

## What I verified here

- Backend: 751 tests, including PostgreSQL 16, MariaDB 10.11 and SQL Server 2022 live.
- Frontend: 180 unit tests, lint and build.
- Browser: 14 tests (`npm run e2e`), including the newcomer's five first steps on the Factory demo
  in English and Russian. A scripted walk of the same steps took 17 actions in each language with no
  browser errors.
- Known limits: the line filter is typed, not picked from a list, and grouping by *Line* shows line
  numbers (value pickers and names in place of IDs are M12). The demo's scrap metric is an average per
  report (ratio metrics are M12). Date pickers follow the browser's language.
