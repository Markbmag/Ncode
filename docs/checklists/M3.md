# M3 · Visualisation engine: manual checklist

Install: `cd frontend && npm install` (new: echarts), `cd backend && pip install -r requirements-dev.txt`
(new: xlsxwriter; openpyxl for tests). Then `pytest`, `npm test`, `npm run build`, `npm run lint`.

## 1. "Done when"

- [ ] Admin → **Chart gallery**: all 23 cards draw (no empty card, no error), in dark **and** light
      theme (switch with the moon/sun button). Note anything clipped or hard to read.
- [ ] Settings round-trip: change a chart's settings, reload the page → the same chart comes back.

## 2. Charts from your own data

- [ ] Questions: "revenue by month by region" → **Chart** → a line per region (badge *auto*).
- [ ] Settings → Bar → *Stacked* → *100 %*; *Value labels*; a goal line; *Horizontal*.
- [ ] A category with many values → Bar → *Only the largest* 5 → the rest becomes *Other*.
- [ ] *Highlight one series* greys the others; give a series a colour, filter another series away
      in the question → the colour stays with its series.
- [ ] Two measures of very different size on one chart → the note about one shared axis appears.
- [ ] A single number (SQL: `SELECT count(*) ...`) → Chart → number tile; with a month column →
      change vs the previous month and a sparkline.
- [ ] Pie (top 6 + Other), scatter / bubble, histogram, heatmap (two categories + a number), funnel,
      gauge (set min/max), pivot table (rows, columns, values, totals).
- [ ] Number formats: currency EUR, percent, 2 decimals, compact 1.2K, prefix/suffix.
- [ ] *Reset* returns to the automatic choice.

## 3. Downloads

- [ ] PNG and SVG of a chart open correctly (SVG in a browser or Inkscape).
- [ ] Excel (.xlsx): numbers are numbers, dates are real dates (sortable, filterable), the header
      row is frozen; a text value like `=1+1` stays text.
- [ ] CSV as before.

## 4. No regressions

- [ ] Search, Browse, Export (M0 checklist §4) and the builder / SQL editor basics (M2 checklist §1).
