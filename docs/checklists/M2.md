# M2 · Visual builder & SQL editor: manual checklist

Install first: `cd frontend && npm install` (new: CodeMirror 6, react-resizable-panels,
@tanstack/react-virtual, sql-formatter). **Node 22 or newer** is now required.
Then `npm test`, `npm run build`, `npm run lint` → no errors.

Use one of your real databases (read-only) unless a step says otherwise. Note anything that is
slow, confusing or wrong, with a screenshot if you can.

## 1. The "done when" test (time it)

- [ ] Questions → pick an orders-like table → *Join data* → the customers-like table appears under
      "Related (foreign keys)"; pick it.
- [ ] Summarise → *Metric* → "Sum of" the amount column; *Group by* the date column (it offers
      "by month") and the region column. The preview shows one row per month and region.
- [ ] *View SQL* shows the SQL; *Open in SQL editor* → *Run* gives the same numbers.
- [ ] It took under a minute.

## 2. Builder details

- [ ] A table two steps away (e.g. products from customers) is offered "via orders → order items".
- [ ] A table without a foreign key can be joined with your own condition (pick both columns).
- [ ] Filters: text contains, number between, date "in the last 30 days", "this month",
      "is one of" with a comma list; nested *any of* group; switch *all* / *any*.
- [ ] Custom column `[amount] * 2` appears in the column lists; a typo like `[amout]` shows a
      warning instead of running.
- [ ] Filter the summary (e.g. total > 1000) and sort by the metric, descending.
- [ ] With *Live preview* off nothing runs until *Run* or Ctrl/Cmd+Enter.
- [ ] Switching database in the sidebar keeps a separate draft per database.

## 3. SQL editor

- [ ] Autocomplete suggests your table and column names while typing.
- [ ] Ctrl/Cmd+Enter runs; with a selection it runs only the selection.
- [ ] `WHERE code = {{code}}` shows an input; *Number* vs *Text* both work.
- [ ] `DELETE FROM x` shows a red badge before running, and an error if run.
- [ ] *Format*, *History* (restores an old query), the schema tree (*SELECT* button, click names).
- [ ] A slow query → *Stop* ends it within a few seconds (check the database's process list).
- [ ] Drag the dividers between tree / editor / result.

## 4. Results grid

- [ ] 10,000 rows scroll smoothly; resize a column; click a cell + Ctrl/Cmd+C copies; arrows move.
- [ ] *Smart dates* on a column with `31.01.2026` or unix times shows real dates.
- [ ] CSV download opens correctly in Excel (semicolon option).

## 5. Themes, phones, no regressions

- [ ] Light and dark theme (editor colours follow).
- [ ] Phone-sized window: builder above the result, SQL editor stacked.
- [ ] Search, Browse and Export as in the M0 checklist, section 4 (quick pass).
