# M9 · Admin & production: manual checklist

Install: no new packages. The app database gets three tables and two columns on start
(**back up `backend/data/ncode.sqlite` first**). Then `pytest`, `npm test`, `npm run build`, `npm run lint`.
CI runs the same on GitHub for every push (Actions tab).

## 1. People and groups (Admin → People)

- [ ] **Add user** (name, password, email, role user) → they can sign in; the list shows their last sign-in.
- [ ] Their **Databases** → *Only these* with nothing ticked → they see no databases.
- [ ] **Add group** "Sales" with database Shop and the user as member → the user sees Shop again.
- [ ] Library → a collection → **Share** → *Group: Sales* can view → the user sees its questions.
- [ ] **Set a new password** for the user → they are signed out and sign in with the new one.
- [ ] Try to demote or disable the last admin → refused.
- [ ] As the user: the account button (envelope, bottom left) → **Change your password** → other browsers are signed out.

## 2. Row-level security

- [ ] Admin → People → **Row-level security** → group Sales, database, a table with a region/country
      column, values e.g. `EU` → Add.
- [ ] As a member: a question on that table, a dashboard, Browse and its CSV export show only EU rows;
      the joined table in a question too. The SQL editor on that database says SQL is not available.
      Search does not search that table.
- [ ] As an admin, and as a user outside the group: all rows.
- [ ] A rule with `{username}` (e.g. a column holding the user name) → each person sees their own rows.
- [ ] Delete the rule → all rows again.

## 3. Audit (Admin → Audit)

- [ ] Sign-ins, searches, queries, exports and admin changes are listed; filter by person, action,
      text and dates; **CSV** downloads the filtered list.

## 4. System (Admin → System)

- [ ] **Back up now** → a zip appears; *Download* → it contains `ncode.sqlite`, `manifest.json` and
      `datasets/` (no `secret.key`).
- [ ] Restore test on a copy: stop the backend, `python -m app.manage restore <zip>`, start → the data
      of the backup is back; the old files are kept as `*.before-restore-…`.
- [ ] Health tiles: ready, app database ok, scheduler running, disk free, last backup.
- [ ] `http://localhost:8000/api/health/ready` answers `{"status": "ok", ...}`; `/metrics` needs an
      admin session or `NCODE_METRICS_TOKEN`.

## 5. Languages

- [ ] **EN / RU** button next to your name (and on the sign-in page) → Русский → the page reloads in
      Russian: menu, home, search, browse, questions, SQL editor, charts, library, dashboards, Combine,
      uploads, profiles, subscriptions, sharing, admin. Back to English the same way.
- [ ] Error messages from the server stay English (expected).

## 6. Docker (on a machine with Docker)

- [ ] `.env` next to `docker-compose.yml` with `NCODE_SITE=<name or localhost>`; `docker compose up -d --build`.
- [ ] `docker compose exec backend python -m app.manage create-user <you> --admin`.
- [ ] `https://<name>` opens (after trusting Caddy's root certificate, see docs/guide/install.md);
      `http://` redirects to `https://`. Search (live progress), a question, a dashboard work.
- [ ] `docker compose restart` keeps users, questions and uploads (volume `ncode-data`).

## 7. No regressions

- [ ] Search, Browse, Export (M0), builder and SQL editor (M2), charts (M3), library and sharing (M4),
      dashboards (M5), Combine and uploads (M6), profiles, X-ray, data model (M7), subscriptions and
      alerts (M8).
