# M7 · Analysis toolkit & semantic layer: manual checklist

Install: no new packages (uses DuckDB from M6). The app database gets three tables and a column on
start (**back up `backend/data/ncode.sqlite` first**). Then `pytest`, `npm test`, `npm run build`, `npm run lint`.

## 1. "Done when": profile, X-ray, a metric in a question and on a dashboard

- [ ] **Browse** → a table → **Profile**: one card per column (empty values, distinct values,
      min/median/mean/max, histogram, top values); numbers get the correlation table at the bottom.
      "N rows profiled of M": on a big table only the first rows are read (the cost guard).
- [ ] **X-ray** (next to Profile): cards for rows, sums, over time, per category, distributions.
      **Save as dashboard** → a dashboard with the cards, which are saved questions in your collection.
- [ ] **Admin → Data model** → your database → **Metric**: e.g. *Paid revenue* = Sum of total, only
      rows where status = paid, format money EUR → Save.
- [ ] **New question** → the table → Summarise → **★ Saved metric** → *Paid revenue*, group by month
      → the column shows euros. Save it, put it on a dashboard → same numbers.
- [ ] Change the metric (e.g. remove the condition) → the question and the card show the new numbers
      at once. Archive it → it leaves the picker; the saved question still runs.

## 2. Data model

- [ ] Click a column → display name + description → the builder shows the name, the result header
      shows it (tooltip: the real name and the description).
- [ ] Format money / percent / decimals → tables and charts use it (a chart's own format still wins).
- [ ] **Hidden** → not offered in the builder, not in "all columns"; still works in SQL.
- [ ] A text column with dates (`31.01.2026`, `2026-01-31 08:15`, unix time): **Read as dates** → the
      builder treats it as a date: filter "last 30 days", group by month. Odd values become empty.
      (The Profile shows "N % of the values look like dates" with a shortcut for admins.)
      On PostgreSQL a value like `31.02.2026` stops the query - tell me if your data has such values.
- [ ] A database without foreign keys: **Relationship** (orders.customer_ref → customers.id) → in the
      builder, Join customers needs no condition any more; remove it → the join asks again.

## 3. Calculations and charts

- [ ] Revenue by month → **Calculate** → *Compare with previous* (last year) → two new columns (the value
      a year earlier and the change in %); a month missing last year stays empty.
- [ ] Running total, moving average (3 rows), % of total (within each month), rank, flag outliers.
- [ ] Revenue by month **and region**: the running total restarts per region.
- [ ] SQL editor → **Calculations** → the same on a SQL result; save → reopen → still there.
- [ ] Line chart → Settings → **Trend line**, **Forecast** 3 → a dashed line continuing 3 months.
- [ ] Any result → **Profile** (next to Download) → a profile of the rows on screen, no new query.

## 4. Models

- [ ] A saved question → ⋯ → **Use as a model** → badge *model* (also in the Library).
- [ ] **New question** → *… or start from a model* → opens Combine with it as the source; filter,
      summarise, save.
- [ ] A builder question → ⋯ → **X-ray** keeps its filters.

- [ ] Search, Browse, Export (M0), builder and SQL editor (M2), charts (M3), library and sharing (M4),
      dashboards (M5), Combine and uploads (M6).
