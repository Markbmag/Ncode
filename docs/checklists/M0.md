# M0 · Foundations: manual checklist

Run on your own machine (Python 3.14, your real databases). Tick each line; report anything
that fails with the exact message.

## 0. Before you start

- [ ] **Back up `backend/data/`** (it holds `ncode.sqlite` and `secret.key`).
- [ ] Backend: `cd backend && pip install -r requirements-dev.txt` (new: `alembic`).
- [ ] Frontend: `cd frontend && npm install` (new: `react-router-dom`, `@tanstack/react-query`; upgraded: `framer-motion` 11).

## 1. Automatic checks

- [ ] `cd backend && pytest` → all pass (113 in my environment).
- [ ] `cd frontend && npm run build` → no errors.
- [ ] `cd frontend && npm run lint` → no errors.

## 2. Migrations

- [ ] Start the backend on your **existing** `ncode.sqlite`. It starts, you can sign in with your
      current users, and your UI-added databases are still there.
- [ ] `cd backend && alembic current` prints `0001 (head)`.
- [ ] Fresh install: `NCODE_APP_DB=/tmp/fresh.sqlite python -m app.manage create-user test --admin`
      works, then `NCODE_APP_DB=/tmp/fresh.sqlite alembic current` prints `0001 (head)`.

## 3. New shell and navigation

- [ ] The sidebar shows Home, Search, Browse, Questions / SQL editor / Dashboards (marked *soon*), Admin (admins only).
- [ ] A non-admin user does not see Admin; typing `/admin` sends them to Home.
- [ ] Reloading the browser on `/browse` keeps you on Browse; signing in from a link to `/browse` lands on Browse.
- [ ] An unknown URL such as `/xyz` goes to Home.
- [ ] Phone-sized window: sections appear as a strip under the logo; the database picker is above the page.
- [ ] Light and dark theme both look right.

## 4. No regressions: Search, Browse, Export

- [ ] Search a phrase on each engine you use (MySQL, PostgreSQL, SQL Server, SQLite): progress, results, highlights.
- [ ] Stop a running search.
- [ ] Scope: pick tables / skip patterns, the label updates, the search respects it.
- [ ] Results → **Open in table view** goes to Browse with the phrase applied; the browser's **Back**
      returns to Search with the results still there.
- [ ] Browse: paging, sorting, filter, Structure tab, row drawer.
- [ ] Export CSV from the results panel (both delimiters) and from Browse (streamed file opens in Excel, Cyrillic OK).
- [ ] Admin: add, edit and delete a database from the UI; the list refreshes everywhere.
- [ ] Sign out, sign in as another user: nothing from the previous user is shown.

## 5. Schema v2

- [ ] Admin → **Data model**: for each of your databases the tables, column types and keys look right.
      Note any column whose type shows as `unknown`, with its `db_type` (hover the badge).
- [ ] Databases with foreign keys list them under *Relationships*. Databases without declared
      foreign keys (common in MES systems) say so.
- [ ] `GET /api/connections/<key>/schema` in http://localhost:8000/docs returns the same.
