# M8 · Automation & sharing: manual checklist

Install: one small new package, `tzdata` (time zones for schedules; Windows has none of its own):
`pip install -r requirements.txt`. The app database gets five tables and a column on start
(**back up `backend/data/ncode.sqlite` first**). Then `pytest`, `npm test`, `npm run build`, `npm run lint`.

To try email without a real server you can use any SMTP test tool (e.g. a company relay or
Mailpit); Slack/Teams need a channel where you may add a webhook.

## 1. Delivery settings (Admin → Delivery)

- [ ] **Site address**: the address colleagues use (not `localhost` if others should open the links).
- [ ] **Email server**: server, port, STARTTLS/SSL, user, password, from address → Save →
      **Send test** to yourself → the test email arrives. Reload: the password field says "unchanged".
- [ ] **Chats and webhooks** → Add → Slack (Incoming Webhook URL) or Teams (Workflows URL) or Telegram
      (bot token + chat id) → **Send test** → the message arrives. The list shows only the end of the address.
- [ ] Your email address: the envelope button next to your name (bottom left).

## 2. "Done when": a dashboard subscription, an alert, a public link

- [ ] A dashboard → **bell** → *New subscription*: weekdays 08:00, you + one other address + a chat,
      attach **Excel** → **Preview** shows the email → Save → **Send now** → in a few seconds the row says
      *sent*; the email has the cards (numbers, bars, tables) and one `.xlsx` per question; the chat got
      the headline numbers.
- [ ] Set a dashboard filter value in the subscription → the email shows the filtered numbers.
- [ ] A question that lists problems (e.g. refunded orders) → **⋯ → Set up an alert…** → *has results*
      → Save → Send now → an email "🔔 … : N rows". Change it to *a number goes above* a value that is
      not reached → Send now → *not sent* with the reason.
- [ ] Wait for a scheduled time (choose *every hour* at the next 5 minutes): it arrives without clicking.
- [ ] **Subscriptions** page: yours, and (admin switch) everyone's; pause one, send one, delete one.
- [ ] Admin → **Sharing** → Public links **on** → a dashboard → **⋯ → Public link / embed…** → *Create and
      copy* → open the link in a private window (not signed in): the dashboard with working filters, no
      SQL, no Ncode menu. **Revoke** → the link says "no longer works".
- [ ] A public link with a **password** and **expiry** → the private window asks for the password.

## 3. Embedding (optional)

- [ ] Admin → Sharing → Embedding **on** → *Create the key*.
- [ ] A dashboard → Public link / embed → **Embed** → allow, a filter **Locked** → Save → **Preview** → the
      dashboard without that filter. The code sample (Python / Node.js) signs a token with the key.
- [ ] *New key* → the old preview stops working.

## 4. Usage (Admin → Usage)

- [ ] Queries per day, people, the most used questions and dashboards, where queries come from
      (editor, dashboard, subscription, public link, embed).
- [ ] Query log → **Slow** and **Failed** (set `NCODE_SLOW_QUERY_SEC=1` to see entries quickly).

## 5. Permissions and safety

- [ ] A non-admin sees no *Public link / embed* entry and no Delivery/Sharing/Usage tabs.
- [ ] A non-admin cannot subscribe to a dashboard that is not shared with them.
- [ ] A user who receives someone else's subscription sees it on the Subscriptions page and can
      *Unsubscribe me*, but not change it.
- [ ] Disable the owner of a subscription (`python -m app.manage disable <name>`) → Send now → *failed*:
      "The owner of this subscription is disabled".

## 6. No regressions

- [ ] Search, Browse, Export (M0), builder and SQL editor (M2), charts (M3), library and sharing (M4),
      dashboards (M5), Combine and uploads (M6), profiles, X-ray, data model (M7).
