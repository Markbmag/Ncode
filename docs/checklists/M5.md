# M5 · Dashboards v2: manual checklist

Install: `cd frontend && npm install` (new: react-grid-layout 2.2.4). Backend: no new packages; the app
database gets two new tables on start (**back up `backend/data/ncode.sqlite` first**).
Then `pytest`, `npm test`, `npm run build`, `npm run lint`.

You need a few saved questions (M4) and, for the permission part, a second non-admin user.

## 1. "Done when": 6 cards, 2 filters, layout, refresh, permissions

- [ ] Dashboards → **New dashboard** → it opens in edit mode. Add 4 questions (**Question**), one
      **Text** card and one **Heading** = 6 cards. Cards fill the space left to right.
- [ ] Drag a card by its title bar, resize one from its bottom-right corner → **Save** → reload the
      page: every card is where you left it.
- [ ] **Filters** → add a *Date range* (e.g. "Period") and a *List of values* (e.g. "Region").
      Connect each to at least one card: a question parameter, or a column (builder questions).
      Apply → Save.
- [ ] Change a filter: only the connected cards reload; their badge says "1 filter". The URL now
      contains `?f.period=…` - open that link in a new tab → same values.
- [ ] ↻ reloads every card; *Every 30 s* keeps refreshing (watch the numbers or the tooltip time).
- [ ] As the second user (collection shared *Can view*): the dashboard opens with *view only*, no
      Edit button; a card whose question is in a collection they cannot see says "not shared with you".
- [ ] Give them *Can edit*: they can move cards and save, but adding a question they cannot see is refused.

## 2. Cards

- [ ] Text card with `# Title`, **bold**, a list and a link renders nicely; a `javascript:` link
      shows as plain text.
- [ ] ✎ on a question card → own title; the table/chart button switches only this card.
- [ ] Card ⋯ → *Open in editor* opens the question with the dashboard's parameter values;
      CSV, Excel and PNG downloads work.
- [ ] Archive a question that is on a dashboard → card shows "archived" but still works; delete it
      for good → card says "deleted" (remove it in edit mode).
- [ ] A card whose question fails (e.g. a column was renamed in the database) shows the error and
      *Try again*; the other cards are fine.

## 3. Tabs, TV, print

- [ ] Edit → **Tab** twice → cards are on "Overview"; add cards to the second tab; double-click to
      rename; remove a tab → its cards move to the first tab.
- [ ] **TV mode**: full screen with only the dashboard; Esc leaves it.
- [ ] ⋯ → *Print / save as PDF*: no sidebar, cards not cut in half (check in the print preview).
- [ ] On a phone (or a narrow window) cards are stacked one per row.

## 4. Library and import

- [ ] Library → a collection lists its dashboards; **New dashboard** there saves into it.
- [ ] Star a dashboard → it is under *Favourites* (Dashboards page and Library start page).
- [ ] Archive a dashboard → Library → Archive → *Restore* / *Delete*.
- [ ] DataDesk: re-run `python -m app.manage import-datadesk … --map …` on the earlier import →
      "Dashboards: … new: N" and real dashboards appear (cards two per row).

## 5. No regressions

- [ ] Search, Browse, Export (M0), builder and SQL editor (M2), charts (M3), library and sharing (M4).
