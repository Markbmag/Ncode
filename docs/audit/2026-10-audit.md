# October 2026 audit: newcomer experience and bugs

Input for release v2 (ROADMAP §8b). Three parts: a newcomer walkthrough of the running app, a bug
hunt, and research on how other products help people without BI experience. Items are ticked off
in M10 (bugs) and M11–M16 (experience).

## 1. Newcomer walkthrough

Eight newcomer tasks run in a browser as a normal user (and as admin for admin tasks), at desktop and
phone width, in English and Russian: first sign-in, find a value, browse a table, "orders per month",
"top 5 products by revenue", save and build a dashboard with a date filter, share and subscribe,
combine two databases and upload a file, add a database and a user, Russian UI.

### Friction, most harmful first

| # | Where | What happens | Change | Milestone |

### Bugs found on the way (all for M10)

1. Cyrillic rejected in custom column names and stripped from result names (`CustomColumnsEditor.tsx`, `SummarizeEditor.tsx`).
2. Windows-1251 CSV upload fails with a raw DuckDB error (`UploadDialog.tsx`, datasets backend).
3. Dashboard date range loses its start when both ends are set quickly (`FilterBar.tsx` builds the pair from values captured at render).
4. Russian layout overflow: custom-column *Add* button, "по месяцам" cut off.
5. Combine join row overflows at 1440 px (compare dropdown).
6. After changing the table of a saved question, the *Chart* tab is active while the chart type says *Table*.
7. Admin → Usage shows the internal chart note "These series differ a lot in size…".

### Works well (keep)

Clear sign-in errors and connection-check messages · joins suggested from foreign keys, including two
steps · live preview while building · Combine suggests the join key and explains the match · email
preview · empty states that name the next step · phone layout without sideways scrolling · fast saves.

**Pitfalls to avoid**

- Natural-language querying is unreliable on real schemas: Tableau retired *Ask Data*, Microsoft is
  retiring Power BI Q&A (Dec 2026) for Copilot, and benchmark agents solve a minority of enterprise
  tasks (Spider 2.0), mostly failing on picking the right tables and columns. So: metadata first
  (M11, M14), AI last (M16), and AI output is always an editable question, never run unseen.
- Up-front tutorials don't help (NN/g); prefer hints at the point of need.
- Features that silently don't work for SQL questions confuse people; say why.
- Automatic insights must say "nothing notable" instead of showing noise.
- Too much curation blocks people; verified content and free exploration live side by side.
- Templates: few, curated, with documented column mapping.
- Synonyms and glossary must be bilingual (EN / RU).
