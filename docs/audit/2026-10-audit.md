# October 2026 audit: newcomer experience and bugs

Input for release v2 (ROADMAP §8b). Three parts: a newcomer walkthrough of the running app, a bug
hunt, and research on how other products help people without BI experience. Items are ticked off
in M10 (bugs) and M11–M16 (experience).

## 1. Newcomer walkthrough

Eight newcomer tasks run in a browser as a normal user (and as admin for admin tasks), at desktop and
phone width, in English and Russian: first sign-in, find a value, browse a table, "orders per month",
"top 5 products by revenue", save and build a dashboard with a date filter, share and subscribe,
combine two databases and upload a file, add a database and a user, Russian UI.

### Friction, most harmful first

| # | Where | What happens | Change | Milestone |
|---|---|---|---|---|
| 1 | Saved question | Opens straight into the editor with all 9 steps; the chart gets about half the screen; changing the table silently wipes joins, summaries and sort; no undo; *Start over* doesn't ask | Open in **view mode** with *Edit*; confirm destructive changes; undo / redo | M12 |
| 2 | Builder | Nine steps shown at once, SQL words ("Like HAVING in SQL", Left/Inner/Full join, Metrics); *Custom columns* vs *Calculate* look alike; two add buttons | Data · Filter · Summarise first, the rest under *More*; plain words | M11, M12 |
| 3 | "Top 5 products by revenue" | About 13 actions incl. a formula; results show `sum_revenue`, `created_at_month`; "Descending"; literal `null` | *Top N by…* shortcut; readable result names; "Biggest first"; `null` shown as "—" | M12 |
| 4 | Home and menu | Nine equal tiles mirroring ten overlapping menu items; the current database is chosen silently in the sidebar | "Start here" path, recent items, explicit database picker per page; group the menu | M11 |
| 5 | Everywhere | Raw names (`q_order_items`, `customer_id`), SQLite file path as subtitle, connection keys; normal users see the "defined in .env" lock; tables have no display names | Display names for tables and databases; hide technical details from non-admins | M11 |
| 6 | Builder, Russian | Cyrillic names rejected for custom columns and silently stripped from result names; some server messages, "X-ray", "ms" untranslated | Allow any letters; translate the rest | **M10** |
| 7 | Uploads | Windows-1251 CSV fails with a raw error, 1251 not offered; decimal comma read as text; jumps to Combine after upload | Detect 1251, offer encodings, decimal comma option, stay on the upload | **M10** |

| 11 | Search | Numbers & dates off by default, so "42" finds nothing, with no hint; help panel cramped | Search numbers when the text is a number; say what was searched | M14 |

### Bugs found on the way (all for M10)

1. Cyrillic rejected in custom column names and stripped from result names (`CustomColumnsEditor.tsx`, `SummarizeEditor.tsx`).
2. Windows-1251 CSV upload fails with a raw DuckDB error (`UploadDialog.tsx`, datasets backend).
3. Dashboard date range loses its start when both ends are set quickly (`FilterBar.tsx` builds the pair from values captured at render).
4. Russian layout overflow: custom-column *Add* button, "по месяцам" cut off.
5. Combine join row overflows at 1440 px (compare dropdown).
6. After changing the table of a saved question, the *Chart* tab is active while the chart type says *Table*.
7. Admin → Usage shows the internal chart note "These series differ a lot in size…".

### Works well (keep)

Clear sign-in errors and connection-check messages · joins suggested from foreign keys, including two
steps · live preview while building · Combine suggests the join key and explains the match · email
preview · empty states that name the next step · phone layout without sideways scrolling · fast saves.

## 2. Bugs

Each bug below was reproduced (on the running test instance or with a temporary app database).
All are M10 work; the first one comes first.

| # | Severity | Bug | Cause | Fix |
|---|---|---|---|---|
| 1 | **High (security)** | **Row-level security bypassed through the result cache** in table profile, X-ray and multi-source runs: a restricted user who runs the same profile / X-ray / combined question within the cache time after an unrestricted user gets all rows (and the reverse) | `analysis/routes.py` and `federation/routes.py` cache keys hold the spec but not the SQL after row rules | One cache-key helper that always includes the final, rule-applied SQL of every statement |
| 2 | Medium-high | Stopping a profile / X-ray / combined run (or its timeout) can cancel **another user's** running query | `query/runner.py` leaves the cancel hook pointing at a pooled connection after use; `federation/engine.py` cancels finished child tasks | Clear the hook in `finally` inside the connection block; mark children finished |
| 3 | Medium | NaN / ±Infinity values (PostgreSQL float) give a 500 without CORS headers - the UI says "server not reachable" | `serialize.py` passes them to JSON | Map to empty; a global JSON error handler with CORS headers |
| 4 | Medium | A dashboard with a deleted question can't be duplicated (500) or saved until the card is removed by hand | `content/dashboards.py` validates before dropping orphan cards | Drop or keep orphan cards before validation, with a clear message |
| 5 | Medium | CSV with a quoted multi-line cell refused | `null_padding` with DuckDB's parallel CSV reader | `parallel = false` or retry |
| 6 | Medium | Russian / European CSV: no Windows-1251, decimal comma read as text | `ENCODINGS` list; no decimal option | Add 1251 (detect it), decimal-comma option |
| 7 | Medium | On SQLite, case-insensitive search / *contains* / Browse ignore non-ASCII ("иван" ≠ "Иван") | SQLite `lower()` is ASCII only | Register a Unicode `lower` on SQLite connections |
| 8 | Low-medium | Values shown wrongly: PostgreSQL JSON and arrays as Python text, big decimals lose precision, integers above 2^53 rounded in the browser, MariaDB `TIME` as "34 days, …", `'infinity'` timestamps break the query | `serialize.py` | JSON for dict/list, exact numbers as text, `HH:MM:SS`, infinity as text |
| 9 | Low-medium | SQLite SQL-mode dates typed as text, so *vs. previous period* fails there | type detection in SQL mode | Detect ISO date text in results |
| 10 | Low | `{{name}}` inside a string or a comment treated as a parameter, then a driver error | `find_params` / `bind_params` use a regex | Skip literals and comments (tokenizer) |
| 11 | Low | DataDesk import fails on paths with `#` or `%` | `content/datadesk.py` builds `file:` URI by hand | `Path.as_uri()` |
| 12 | Low | Library overflows at phone width (action buttons) | layout | Wrap / menu |
| 13 | Low | CSV formula guard misses `-2+3+cmd|…`; non-admins see SQLite file paths; items can be created inside an archived collection and vanish; a huge number parameter gives a raw driver error; Parquet upload error shows a server temp path | various | Small fixes |

**Suspected, to check in M10:** memory use from SQL such as `randomblob(1e9)` in the backend process;
query results kept 15 min regardless of `NCODE_TASK_TTL_SEC` and copied per cached hit (TV-mode
dashboards); connection pool of 8 shared by queries, search, combine and browse (pool timeouts under
load); on Windows an open Parquet file left behind when a dataset is deleted; subscription recipients
stored by user name (a re-created user with the same name would receive them).

**Systemic weaknesses (M10):** no protection against two people editing the same question or dashboard
(the last save silently wins); the audit log has no retention and records every cached and
auto-refresh run, so the app database and backups grow; raw driver messages reach users in many places
and unexpected errors have no JSON body; the cache key is built differently on each path; one cancel
hook per task doesn't fit multi-statement work.

**Checked and fine:** SQL guard (incl. DuckDB escapes in combine SQL), connection permissions, row
rules through joins and aliases, WebSocket sign-in, schedules and time zones, Windows / Python 3.14
wheels for every dependency.

**Pitfalls to avoid**

- Natural-language querying is unreliable on real schemas: Tableau retired *Ask Data*, Microsoft is
  retiring Power BI Q&A (Dec 2026) for Copilot, and benchmark agents solve a minority of enterprise
  tasks (Spider 2.0), mostly failing on picking the right tables and columns. So: metadata first
  (M11, M14), AI last (M16), and AI output is always an editable question, never run unseen.
- Up-front tutorials don't help (NN/g); prefer hints at the point of need.
- Features that silently don't work for SQL questions confuse people; say why.
- Automatic insights must say "nothing notable" instead of showing noise.
- Too much curation blocks people; verified content and free exploration live side by side.
- Templates: few, curated, with documented column mapping.
- Synonyms and glossary must be bilingual (EN / RU).
